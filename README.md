# Round Robin

Простой сайт для расчёта расписания процессов по алгоритму Round Robin. Страница сделана на HTML, CSS и JavaScript, расчёт выполняет Python.

## Задание

Создать простой интерфейс для ввода кванта и параметров процессов. Построить диаграмму Ганта, найти Waiting Time (WT) и Turnaround Time (TAT) каждого процесса и средние значения.

**Условие преподавателя:** квант равен 2. Если процесс приходит в тот же момент, когда у другого заканчивается квант, новый процесс встаёт в очередь раньше вытесненного.

| Процесс | Arrival | Burst |
|---|---:|---:|
| P1 | 0 | 5 |
| P2 | 1 | 3 |
| P3 | 2 | 1 |
| P4 | 3 | 2 |

## Запуск

Нужен Python 3. В папке проекта запустите:

```bash
python server.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Использование

Введите квант, Arrival и Burst. Кнопками можно добавлять и удалять процессы. Нажмите **«Рассчитать»**, чтобы увидеть диаграмму Ганта, WT, TAT и средние значения.

## Файлы

- `index.html` — страница, оформление и интерактивность.
- `server.py` — веб-сервер и расчёт Round Robin.
